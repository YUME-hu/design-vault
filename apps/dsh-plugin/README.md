# design-vault-plugin

A DeepSeek Harness plugin.

[中文](README.zh.md)

## Requirements

Node 24+ and pnpm 12 (npm works as a fallback).

## Install

```bash
dsh plugin --profile web add design-vault-plugin
```

For the desktop app, use its plugin page; the `desktop` profile is managed by the application.

## Verify

```bash
dsh --profile web --dump-config | grep -A2 "id: design-vault-plugin"
```

## Develop

```bash
pnpm install
pnpm verify   # format → lint → typecheck → tests → build → pack
```
npm works too: `npm install && npm run verify`.

- `src/host/` — Host half (Node).
- `src/client/` — browser half; the ModuleLoader wrapper is generated by `tsdown.config.ts`.
- `lib/` — generated, committed (a `link:` install never builds).
- `tests/` — host and client suites.
- `AGENTS.md` / `llms.txt` — agent-facing context.
- `PUBLISHING.md` — release checklist.

## Vault data source

- **Desktop app (dsh-app://)**：DSH 桌面端的 CSP 不允许插件向 http://localhost:3000 发起请求，插件使用打包的静态快照（内置 VIBES 调色板）。需要读取最新入库风格时，请在浏览器中打开 DSH。
- **Browser mode**：在浏览器打开 DSH 时，插件会请求 http://127.0.0.1:3000/api/vault/styles-lite（失败再试 localhost），成功后侧栏出现「静态快照 / 远程风格」下拉。
- 数据来源：src/client/index.tsx 的 Vault 服务区块；Web 端路由 apps/web/app/api/vault/styles-lite/route.ts。
