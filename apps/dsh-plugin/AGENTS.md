# design-vault-plugin — agent notes

Read this before changing code. User docs: [README.md](README.md).

## Commands

```bash
pnpm install
pnpm verify        # format → lint → typecheck → test → build → pack
pnpm typecheck
pnpm test
pnpm build
```

## Layout

- `src/host/` — Host half: services, tools, routes. No browser APIs.
- `src/client/` — browser half: React 19 components (TSX), slots, styles. No Node APIs.
- `src/shared/` — constants both halves import (`NAME`, `NS`, `PLUGIN_ID`).
- `lib/` — generated. Never edit by hand.
- `tests/` — one suite per half.

## Invariants

- `package.json` `name` === `src/shared/constants.ts` `NAME` === the client bundle id.
- The `window.__ModuleLoader__.load` wrapper is generated by `tsdown.config.ts`; source must not contain it.
- No network calls, no telemetry, no `console.log` in shipped code.
- Any destructive action must be reversible and must state its consequence.

## Design guidance

`src/shared/guidance.ts` is the single source of truth for how this plugin's
output must look and move: the 20 motion recipes, the 16 anti-slop gates, and the
measured hard specs. Its content is imported from the **motion-web** skill
(github.com/feitangyuan/motion-web) — `SKILL.md`, `references/design-slop.md`,
`motion-tokens.md`, `handfeel.md`, `page-design.md`, `components.md`.

It feeds three consumers, and none of them may keep its own copy:

- `src/client/preview-doc.ts` reads `guidance.motion` for the recipe list **and
  its per-recipe duration/easing**, so the canvas animates with the same tokens
  it publishes (class `fx-<position>`);
- `buildDesignConfigExport` embeds the whole `guidance` object in every export;
- `src/client/prompt.ts` renders it into the 生成提示词 text.

Rules:

- Add or rename a motion recipe in `guidance.ts`, never in the canvas alone —
  positions are the contract between the list and the CSS.
- `guidance.version` and `guidance.source` travel inside every export. `source`
  is `motion-web` from 1.0.0 on; only a full re-import of the skill should bump
  the major, and a derived edit bumps the minor.
- Timing numbers come from the motion-tokens duration scale and easing
  dictionary. Do not invent a duration in the canvas that the guidance does not
  list: if a recipe needs one, add the token there first.
- The canvas must obey the anti-slop gates it ships. Breaking one is a decision
  to state out loud in the report, not to leave silently in the code.
