## 与计划书的偏差（需要你确认的 3 点）

1. **手动新建风格的表单没做。** §5.C 提到「手动新建风格」，但 §9.2 的 M0 目录结构与 §9.3 的验收清单都没有这个页面。M0 的手动流程是「编辑 `data/styles.json` → `npm run validate` → 刷新」，`app/library/page.tsx` 末尾留了 TODO。若你认为它属于 M0，我下一步补。
2. **额外加了两个自检脚本**（`scripts/validate-data.ts`、`scripts/verify-m0.mjs`）和 `playwright` 开发依赖。前者让「过 zod」这条可一键复现；后者用真实浏览器验证剪贴板与两档宽度。都是开发期工具，不进运行时依赖。
3. **左栏导航对未开工里程碑做了禁用态**（标 M1/M2/M4、不可点），避免点进空壳页。`/pending` 是例外：允许进入，页面里写清「M2 实现」。
